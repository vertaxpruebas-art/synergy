# Project skills

## caveman

Vendored from [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman) (MIT License).
Ultra-compressed Claude Code communication mode — cuts explanatory filler while keeping
code, commands, and error output verbatim.

Activate in a session with `/caveman` (or say "talk like caveman"). Companion commands:
`/caveman-commit`, `/caveman-review`, `/caveman-stats`.

Only the skill and command files were copied (no global hooks, no statusline, no MCP
middleware) — this is repo-local and has no effect outside Claude Code sessions opened
in this project.
